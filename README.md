# MARS Active Flight Control

Flight computer and Active Flight Control (AFC) system for the
South Dakota Mines MARS IREC rocket.

## Project Goals

- ESP32-S3 flight computer
- FreeRTOS-based flight software
- IMU, barometric, and high-G sensor integration
- State estimation and flight-state detection
- Real-time apogee prediction
- Active aerobrake control
- Reliable flight-data logging
- Hardware-in-the-loop and bench testing

## Status

2026–2027 senior design project. Currently in architecture,
component evaluation, and prototype development.
